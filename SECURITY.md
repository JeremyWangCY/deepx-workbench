# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| < 0.1.0 | No |

## Reporting a vulnerability

Use [GitHub Security Advisories](https://github.com/JeremyWangCY/deepx-workbench/security/advisories/new)
for private vulnerability reports. Include reproduction steps, affected
versions, expected behavior, observed behavior, and logs with secrets removed.

Please do not open a public issue for an unpatched vulnerability.

DeepX executes the official DeepSeek Harness runtime and local plugins. Report
issues in upstream dependencies to their respective maintainers unless DeepX's
integration is required to reproduce them.
